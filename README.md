# Orbit Explorer Quiz

Orbit Explorer is a dependency-free, single-page space exploration quiz. It includes 10 questions, progress tracking, score feedback, persistent personal-best scoring, responsive styling, and light/dark theme support.

## Run locally

Open `index.html` directly in a modern browser. No server, package manager, or build step is required.

## GitHub Pages

The site is deployed automatically from the `main` branch by the workflow in `.github/workflows/pages.yml`. The workflow packages the static repository files and publishes them to GitHub Pages.
